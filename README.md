# Queue Run (가칭 — 기획서의 "Tetrislide")

하나의 입력으로 여러 개의 미로를 동시에 조종하며, 쌓여가는 대기열을 제한시간 안에 처리하는 웹 퍼즐 게임.
빌드 도구 없는 순수 정적 사이트(HTML5 Canvas + JS)라서 GitHub Pages에 그대로 올리면 됩니다.

## GitHub Pages 배포
1. 새 저장소를 만들고 이 폴더의 파일을 루트에 올립니다 (`index.html`이 루트에 있어야 함).
2. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   Branch `main` / `/ (root)` 선택 후 Save.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 플레이.

로컬 실행: `python3 -m http.server` 후 http://localhost:8000 (index.html 더블클릭도 동작).

## 조작
- 방향키 / WASD: **모든 맵이 동시에** 한 칸 이동 (모바일은 스와이프)
- P / Esc: 일시정지, M: 소리 끄기

## 구현 범위 (기획서 1~4단계)
- 격자 맵, 동시 이동, 벽/빨강/초록 판정, 대기열 맵의 선클리어·피격
- 대기열 4개 이상 시 새 퍼즐 추가마다 체력 -1, 체력 0이면 게임오버
- 맵 자동 생성(미로형+흩뿌림형) + BFS 검증 (`mapgen.js`), 빨간 칸은 정답 경로를 막지 않게 배치
- 스토리 10스테이지(5/8/11/15 크기), 챌린지(20초 → 최소 5초), 난이도 3종(HP 5/3/1)
- 고난이도 퍼즐 2~3점(최단 경로 길이 + 분기 수), 최고 점수 저장(localStorage), WebAudio 합성 효과음

## 기획서에 없어서 임의로 정한 값 (`game.js` 상단 상수)
| 항목 | 값 |
|---|---|
| 스테이지 클리어 조건 | 퍼즐 (6 + 스테이지 번호)개 클리어 |
| 스토리 "더 빠른 속도" | 새 퍼즐 간격 20초에서 시작, 스테이지마다 1초 단축 |
| 체력 | 스테이지 간 유지(회복 없음) |
| 대기열 표시 | 왼쪽 2행 격자로 표시, 화면에 안 들어가면 `+N`으로 표시(조작에는 계속 반영) |
| 현재 맵/대기열이 모두 비면 | 즉시 새 퍼즐 추가 |
| 챌린지 맵 크기 | 점수가 오를수록 5 → 8 → 11 → 15 |

게임 이름은 `index.html`의 `<title>`과 `game.js` 메뉴 문구에만 있습니다. 기획서의 권고대로 "Tetrislide"는 쓰지 않았고,
임시로 "Queue Run"을 사용했습니다. 공개 전에 상표/기존 게임명 검색을 해 주세요.
